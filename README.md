# Твой Петербург — упрощённая версия

Статический сайт-квест для GitHub Pages.

## Что изменено
- весь сайт по-прежнему закрыт паролем;
- полностью удалены билеты, ссылки и «хранилище документов»;
- удалены поэтапные таймеры внутри дня;
- добавлена памятка для сборов;
- каждый день открывается утром целиком одной карточкой;
- внутри дня только общая сводка, ритм дня, что взять с собой и короткий поэтичный финал;
- названия ресторанов и подарки не раскрываются.

## Пароль
По умолчанию: `NEVA2026`.

Хэш хранится в `config.js`.

## Когда открываются дни
- 10 сентября — 08:00
- 11 сентября — 07:30
- 12 сентября — 07:30
- 13 сентября — 08:30

Все времена заданы с часовым поясом `+03:00`.

## Как менять тексты
Всё содержимое находится в `config.js`:
- `packing` — памятка для чемодана;
- `days` — четыре главы;
- `unlockAt` — время открытия конкретного дня.

## GitHub Pages
1. Создать репозиторий.
2. Загрузить файлы из этой папки в корень репозитория.
3. Settings → Pages.
4. Source: Deploy from a branch.
5. Branch: `main`, folder: `/ (root)`.
